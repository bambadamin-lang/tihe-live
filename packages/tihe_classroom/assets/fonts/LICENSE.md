# Peyda licence

Peyda is a commercial typeface by Naser Khadem, published by [fontiran.com](https://fontiran.com).
Each file carries the notice: "To use this font, it is necessary to obtain the license from
www.fontiran.com" (licence terms: https://fontiran.com/licenses/).

These files were supplied by the institute for the TIHE app. Embedding them in an app that is
distributed to students (the installer, the auto-update releases) needs fontiran's application
licence, not only a desktop one. Confirm the institute holds it before a public release.

The repository is private; do not copy these files to a public repository. The releases repo is
public and its installer contains the app's fonts, so the licence must cover distribution.
